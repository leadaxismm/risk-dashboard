# لوحة متابعة المخاطر الرقمية – Risk Management Dashboard

مشروع تعزيز سلامة المرضى واستمرارية الخدمات الصحية — مستشفى الولادة والأطفال بحفر الباطن (مشروع أكاديمي، بيانات افتراضية).

- **مصدر البيانات:** Google Sheets منشور بصيغة CSV (قراءة فقط) — ورقة «Risk Register».
- **آلية الربط:** تقرأ اللوحة الرابط المنشور مباشرة في المتصفح. إذا منع المتصفح الطلب (CORS)، تستخدم `data/risk-register.csv` الذي يُنشئه ويُزامنه آليًا من الرابط نفسه كل 10 دقائق عبر GitHub Actions (`.github/workflows/sync-csv.yml`).
- **التحديث:** زر Refresh Data + تحديث دوري كل 5 دقائق. يُحدّث Google النسخة المنشورة عادةً خلال دقائق من التعديل، لذا لا يكون التحديث لحظيًا.
- **حدود التصنيف (أكاديمية):** منخفض 1–4، متوسط 5–9، مرتفع 10–16، حرج 17–25 — Risk Score = Probability × Impact.
